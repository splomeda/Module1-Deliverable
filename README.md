# Module1-Deliverable

GIT 337 - Module 1 Deliverable / Arizona State University

Authored by Steven Plomedahl

This is a single-page website for a fictitious halloween supply store intended for anyone into Halloween and costumes. This website uses HTML and CSS and has no javascript.

The HTML is semantic and validated.

Resets: I used box-sizing: border-box for consistent box sizing and 0 for margin and padding to remove excess and unwanted space throughout the page, especially the padding/margin inside the main body of the page that causes containers to not be flush against the edges of the viewport. This is noted in the stylesheet as well.

The major token groups were created for font families, text colors, container background colors, accents, links, and drop-shadows. They were named so that they would be easily interpreted.

For the alternate theme (which appears in the footer), colors were changed for:
--section-color3  
--text-light  
--text-dark
--text-hover  
--action-bg
--action-hover  
--accent  
Colors were chosen so that they complimented each other while also providing easily readable contrast.

Testing evidence can be found in supplied pdf file labeled "splomedahl_mod1-deliverable.pdf"
